# OL Premiere

A local-first video editor for Windows. Fast timeline editing, near-lossless export, and your footage never leaves your machine.

**[Download for Windows →](https://github.com/dluxpixel/olpremiere/releases/latest)**

Run the `OL-Premiere-*-setup.exe`. That's the whole install — it updates itself from then on.

- **Real export quality** — a native encoder with a visually-lossless option, far past what a browser can do.
- **Everything you need** — timeline editing, effects, titles, auto-captions and keyframe animation.
- **Yours** — projects and media stay local. No account, no upload.

Windows 10 / 11, 64-bit. Unsigned, so the first install shows a SmartScreen warning — More info → Run anyway.
